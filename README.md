# SIEM Projects

Hands-on projects and labs focused on **Security Information and Event Management (SIEM)**, SOC operations, log analysis, threat detection, and incident investigation.

The goal of this repository is to learn SIEM through practical projects rather than theory alone.

## 🎯 Goals

* Understand SIEM architecture and core concepts
* Collect and analyze security logs
* Identify suspicious activity and security events
* Create and tune detection rules
* Investigate alerts and incidents
* Practice SOC analyst workflows
* Understand event correlation
* Work with real-world security scenarios
* Map detections to MITRE ATT&CK techniques

### Incident Investigation

Each investigation aims to follow a practical SOC workflow:

```text
Event
  ↓
Alert
  ↓
Triage
  ↓
Investigation
  ↓
Evidence Collection
  ↓
Determine Impact
  ↓
Response
  ↓
Documentation
```
